Use this when entries are in the Google Sheet but do not show on a village page or in the totals here. It finds entries left in a village's earlier tab (for example after its tehsil was changed in the sheet), puts them back, and counts every village again from its own tab, which also picks up anything typed into the sheet by hand. Each village page is made with the generator and saves into this portal's Google Sheet, one tab per village. Anyone with a village link can view it; entering data needs the edit PIN. Figures here update every time a village saves. Run the portal check if a page does not save.
